# apps/ios — Student / Parent App (SwiftUI)

**Status:** placeholder — scaffolded in **Phase 5** of `docs/cowork-brief.md`.

This will be the native iOS app (Swift, SwiftUI) for students and parents, hosting the
Tutor Agent experience. It is an Xcode project, **not** a JS/TypeScript workspace, so it is
intentionally excluded from `pnpm-workspace.yaml` and Turborepo.

iOS uses the Supabase **anon key only** (never the service role key). The Xcode project is
created in Phase 5; the Apple Developer account is purchased only after local testing confirms
a satisfactory MVP.
